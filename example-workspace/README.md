# Example workspace

Select this `example-workspace/` folder with **Add workspace** in the DARTWIC Interface. It contains the mock rocket project, schematic, Lua DCode, task bindings, and authored startup channels. The repository-level [README](../README.md) has launch, operating, recording, and shutdown steps; [walkthroughs](../walkthroughs/01-device-driver.md) explain how each part is built.

The repository's `tools/` and `flight-computer/` folders sit beside this workspace. Keep them together when extracting the downloadable package. Runtime data and credentials are created locally and are not part of the authored workspace.
